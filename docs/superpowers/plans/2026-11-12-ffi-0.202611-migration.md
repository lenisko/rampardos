# maplibre-native-ffi 0.202611.0 migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move PR 19's renderer from maplibre-native-ffi v0.202610.3 to
v0.202611.0, and delete the workarounds the new release makes unnecessary,
before the large install collects its baseline.

**Architecture:** The Go binding moves to `maplibre.org/maplibre-native-ffi`
and links the C library statically from a preset module, so the Dockerfile's
`.so` download, pkg-config and rpath go. Workers render through
`MapHandle.AttachOffscreen` on one process-wide offscreen device (desktop GL,
created by the library), replacing our own EGL context and the removed owned
texture. Style loads now fail their command, and stills retry failed glyphs,
so the style-failure state machine and the retire-after-glyph-failure rule go.

**Tech Stack:** Go 1.26, cgo, maplibre-native-ffi v0.202611.0 (EGL presets),
Mesa llvmpipe (surfaceless EGL), Docker.

**Spec:** No separate spec. The authority is the v0.202611.0 release notes
(`gh release view v0.202611.0 --repo maplibre/maplibre-native-ffi`) and the
API mapping below, read from the module source at
`$(go env GOMODCACHE)/maplibre.org/maplibre-native-ffi@v0.202611.0/bindings/go/maplibre/`
(`generated_api.go`, `completion.go`) and
`include/maplibre_native_c/{offscreen,map,runtime}.h`. CLAUDE.md's renderer
invariants stay binding unless a task below retires one.

- Linux tests run only in Docker. The test runner below replaces
  `/tmp/churn/rtest.sh`, whose `PKG_CONFIG_PATH` no longer applies.

**Test runner** (`scripts/rtest.sh`, created in Task 1, committed):

```bash
#!/bin/bash
# rtest.sh <image-tag> [go test args...]: build the test stage, then run
# go test in it with Mesa installed (the renderer needs EGL at runtime).
set -e
tag=$1; shift
cd "$(dirname "$0")/.."
docker build -q --target rampardos-test -t "$tag" . >/dev/null
docker run --rm "$tag" sh -c "apt-get update -qq >/dev/null && apt-get install -y -qq --no-install-recommends libegl1 libegl-mesa0 libgl1-mesa-dri libgles2 sqlite3 >/dev/null 2>&1; CGO_ENABLED=1 go test -count=1 $* 2>&1 | grep -vE '^time='"
```

## API mapping (old → new)

Renames: `NewRuntime(RuntimeOptions{})` → `NewRuntime(nil)`;
`RenderBackendFlagOpenGl` → `RenderBackendFlagOpenGL`; `UrlMatchFlagGlob` →
`URLMatchFlagGlob`; `ResourceRoute.Url` → `.URL`;
`ResourceRequestInfo.RequestedUrl/ResolvedUrl` → `RequestedURL/ResolvedURL`;
`RuntimeEventSprite.Id/Url` → `ID/URL`; `SetStyleUrl` → `SetStyleURL`;
`RenderSessionHandle.Resize(LogicalExtent)` → `Resize(LogicalSize{Width, Height})`.

Gone: `AttachOpenGlOwnedTexture`, `OpenGlOwnedTextureDescriptor`,
`OpenGlContextDescriptor*`, `EglContextDescriptor`,
`OpenGlContextOwnershipDedicated`, `NativePointer`, every `Close()`.

New: `NewOffscreenDevice(*OffscreenDeviceOptions) (*OffscreenDeviceHandle, error)`;
`MapHandle.AttachOffscreen(OffscreenDescriptor{LogicalSize}, RenderSessionAttachOptions, *OffscreenDeviceHandle) (*RenderSessionHandle, *Future[struct{}], error)`;
`Release() *Future[…]` (waits, ordered session → map → runtime) and
`Dispose() error` (any state, background); `RenderResultFailed` disposition
(session failure, read `GetFailure()`); `SetStyleURL`'s Future fails with a
native error on a parse error or missing file.

## Review Focus

1. Teardown order and bounds: session, then map, then runtime, each
   `Release()` awaited within `settleTimeout`, falling back to `Dispose()`.
   A hang here strands a worker goroutine and its global slot (`heldSlot`).
   Task 1's retirement and close tests cover it; reviewer checks the fallback.
2. The process-wide offscreen device outlives every session: created once in
   `NewGoPoolRenderer`, released in `Close()` only after every pool has
   closed. A reload must not release it (Task 1 reload tests).
3. A style that fails at a reload keeps the old pool serving: `init()` now
   fails on a bad style, so the rebuild fails, and the existing "failed
   rebuild keeps serving" path must hold (Task 2 test).
4. A glyph failure must not leave a stale resource name that mislabels a later,
   unrelated failure (Task 3 test).
5. The image still runs without a GPU and without `EGL_PLATFORM` set
   (Task 4 smoke run).
